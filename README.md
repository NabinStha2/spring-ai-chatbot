# Spring AI Chatbot

A locally running AI chatbot built with **Java, Spring Boot, Spring AI, and Ollama**. This project integrates a locally hosted Large Language Model (LLM) with a Spring Boot REST API, without relying on paid AI APIs.

## Tech Stack

- Java 21
- Spring Boot 4.1.2
- Spring AI 2.0.2
- Ollama
- Llama 3.2 (3B)
- Maven
- Postman

## Prerequisites

Make sure you have installed:

- Java 21 or later
- Maven (or use the included Maven Wrapper)
- Ollama
- Postman (for API testing)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/NabinStha2/spring-ai-chatbot.git
cd spring-ai-chatbot
```

### 2. Download the Ollama model

```bash
ollama pull llama3.2:3b
```

### 3. Start Ollama

```bash
ollama serve
```

If Ollama is already running in the background, you can skip this command.

### 4. Run the Spring Boot application

```bash
./mvnw spring-boot:run
```

The application starts at:

`http://localhost:8080`

## API Endpoint

### Chat with AI

| Property | Value |
|---|---|
| Method | POST |
| Endpoint | `/api/chat` |
| Content-Type | `text/plain` |

**Request:**

```http
POST http://localhost:8080/api/chat
Content-Type: text/plain
```

Request body:

```text
Explain Spring Boot in simple words.
```

**Response:**

The API returns a text response generated by the locally running Llama model.

## Configuration

The Ollama connection and model are configured in `application.yaml`:

```yaml
spring:
  ai:
    ollama:
      base-url: http://localhost:11434
      chat:
        model: llama3.2:3b
```
